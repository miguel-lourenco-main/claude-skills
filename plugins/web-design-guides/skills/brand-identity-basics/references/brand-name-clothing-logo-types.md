## Use when
Deciding what *type* of mark to build before touching typography, color, or symbols — the logo-type decision determines everything downstream (production methods, scalability needs, how quickly the mark can stand alone).

## Rules
- Resolve logo type before font/color/symbol choices — type determines how the mark behaves across every production context (embroidery, hangtags, social avatars, headers).
- Four factors should drive the choice: brand tier/positioning (luxury→wordmark/monogram; athletic→symbol conveying movement; streetwear→expressive/subcultural mark; accessible/mass→combination mark for flexibility), production scalability (test at actual output scale — e.g. embroidery/patch size — before finalizing, since fine detail has hard physical limits), audience-recognition timeline (new/unrecognized brands should pair icon with wordmark; icon-only usage is earned only after the pairing has built recognition), and the number of contexts the mark must live in (hangtag ~2-3in, avatar 180x180px, horizontal web nav, stacked mobile header — build a full responsive suite: horizontal, stacked, icon-only, black, white, single-color).
- A wordmark signals confidence through restraint but requires years of consistent, repeated application before it functions as an instant identifier on its own — it is a long-term bet, not a shortcut.
- Monograms/lettermarks work best when the specific initials produce genuine visual interest when interlocked or paired (double-letter combos give symmetry single letters can't) — not every name's initials qualify; test before committing.
- Emblems (badge-style, historically-referencing) build value through consistency, not redesign — once chosen, treat as a long-term fixture rather than something to refresh each season.
- Mascot/animal marks endure when tied to an authentic, biographical origin story (a founder's nickname, a personal reference) rather than an arbitrary choice — the story is what transfers into brand meaning.
- Abstract marks (no literal meaning) generalize globally without culture-specific baggage, but need heavy sustained marketing investment before they can stand alone — always launch paired with a wordmark, transition to icon-only only after market recognition is earned.
- Combination marks (name + icon together) are the most practical default for a new brand operating across many formats, since either element can be deployed independently as recognition grows.
- Ultra-minimalist wordmarks (stripped typography, zero ornament) went through a boom-then-backlash cycle in luxury fashion — choose this direction because it fits the brand's own identity, not because it's what larger houses did some years back; over-adoption led to "bland and overused" reversals in some high-profile cases.
- Streetwear/handwriting-style marks (DIY, appropriated, subcultural) only read as authentic when the brand or founder actually has the subcultural credentials/origin being signaled — the look must be earned, not manufactured.

## Patterns (name — when to use — when to avoid)
- Wordmark — distinctive brand name, long-term brand-building horizon — avoid if you need fast standalone recognition (no time to build the years of repetition it needs).
- Monogram — initials that interlock well, heritage/luxury positioning — avoid if the initials don't produce a visually interesting combined form.
- Lettermark — need for maximum clarity/scalability at very small sizes (labels, avatars) — avoid when the brand wants ornamental/heritage signaling instead of clean simplicity.
- Emblem/badge — building heritage and physical authentication (sewn/embroidered) — avoid for brands not ready to commit to a mark unchanged for years.
- Mascot/animal — a genuine biographical or founder story to tell — avoid manufacturing a mascot with no real narrative behind it.
- Abstract mark — global positioning free of cultural specificity — avoid for early-stage brands without the marketing budget to build recognition from zero.
- Combination mark — new brand needing flexibility across many formats — avoid only once the icon alone has already earned full standalone recognition.
- Minimalist wordmark — when it fits the brand's actual identity — avoid adopting purely because it's currently fashionable among larger competitors.
- Streetwear/handwriting — founder or brand has real subcultural credentials — avoid as a purely aesthetic choice with no authentic backing.

## Anti-patterns
- Choosing a logo type before defining brand tier/positioning.
- Finalizing an emblem/monogram without testing it at actual production scale (embroidery, small patch).
- Launching an abstract icon standalone before the brand has earned recognition.
- Adopting a design direction (e.g. minimalist wordmark, streetwear handwriting) purely because a bigger competitor did.

## Checklist (only if supported)
- Logo type chosen matches brand tier and production reality before typography/color work begins.
- Tested at smallest real production scale (embroidery/patch/favicon) before finalizing.
- Full responsive suite exists: horizontal, stacked, icon-only, black, white, single-color.
- New/unrecognized brand pairs icon with wordmark rather than launching icon-only.
