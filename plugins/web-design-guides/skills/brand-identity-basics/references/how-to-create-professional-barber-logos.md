## Use when
Choosing a logo style and color/type system for a local, personality-driven service business (barbershop specifically, but the style-to-positioning mapping generalizes to salons, cafes, and similar local trade brands).

## Rules
- A logo style should be chosen to match positioning signals the audience already reads correctly: vintage/emblem = tradition and artisanal quality; badge = ruggedness/community/multi-generational; modern minimalist = upscale/style-conscious younger audience; wordmark = when the name itself is distinctive enough to carry the whole brand; monogram = refinement/understated elegance, works well small.
- Color psychology should be chosen deliberately per positioning, not decoratively: black = sophistication/upscale; red = passion/boldness (heritage or edgy); blue = trust/family-friendly; brown/tan = warmth/authenticity (vintage); gold = luxury/premium. Combine no more than 2-3 core colors.
- Limit brand typography to two or three fonts maximum; ornate script should be used sparingly since it becomes illegible at small sizes.
- Consistency across every touchpoint (header, favicon, footer, social profile images, email signatures, booking confirmations) is what builds subconscious trust through familiarity — mismatched logos/colors across even two touchpoints create friction that erodes trust before a customer consciously notices.
- Keep a one-page brand guideline with exact hex/CMYK codes, fonts, and placement rules — this is what prevents inconsistent execution when handing assets to a sign printer, t-shirt vendor, or freelancer.
- For physical production, supply vector files (AI/EPS/SVG) to print/sign vendors — pixel-based files degrade visibly at large physical scale (storefront signage).

## Patterns (name — when to use — when to avoid)
- Vintage emblem (circular/shield, muted earth tones, serif) — classic-service positioning, historic neighborhood, nostalgia-valuing clientele — avoid for a shop targeting trend-forward younger clientele.
- Badge/crest with layered elements — neighborhood institution, working-class/multi-generational audience — avoid for upscale minimalist positioning where ornamentation reads as clutter.
- Modern minimalist (geometric, muted/monochrome, sans-serif) — upscale urban shop, premium pricing, style-conscious younger professionals — avoid where the audience associates minimalism with coldness rather than sophistication.
- Wordmark — a distinctive, memorable shop name worth foregrounding — avoid if the name is generic or hard to render distinctively in type alone.
- Monogram — long shop names, upscale/mature clientele, need for a mark that works small — avoid if the initials don't produce a visually strong combined form.

## Anti-patterns
- Using more than 2-3 core brand colors.
- Ornate script fonts at small sizes (illegible).
- Different logos/colors across sign, social profile, and print materials.
- Handing a sign/print vendor a raster (non-vector) file for large-format output.

## Checklist (only if supported)
- Style choice matches stated positioning (tradition vs. modern vs. upscale vs. community).
- Palette limited to 2-3 colors, typography to 2-3 fonts.
- Logo appears identically across website header, favicon, footer, and social profiles.
- One-page guideline exists with hex/CMYK codes and placement rules.
- Vector source file available for print/signage vendors.
