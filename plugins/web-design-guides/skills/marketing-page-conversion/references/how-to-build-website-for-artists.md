## Use when
Structuring a site for someone selling original work or accepting commissions, where social media drives discovery but the site must close the sale.

## Rules
- Treat social media as top-of-funnel discovery and the owned site as the close: serious buyers migrate from Instagram to a website before purchasing (per Art Basel Survey 2025 / Hiscox Report 2023, cited).
- Core section set: home, portfolio/gallery, about + artist statement, CV/exhibition history, contact/commission process — most portfolios need these five; shop/blog are additive, not universal.
- Display high-resolution images (2000px+ long side) with metadata per piece: dimensions, medium, year, availability.
- Write the artist statement in third person, 150-300 words, focused on conceptual approach/themes — this is what galleries evaluate alongside the work itself.
- Price transparency correlates directly with sales: pieces with visible pricing sell roughly 6x more often than "inquire for price" listings (per Artsy Collector Insights, cited); 95% of collectors call price transparency important.
- Mobile performance is a hard gate: target load under 2 seconds, 44x44px minimum tap targets, working pinch-zoom and swipe gestures for gallery browsing.
- Use descriptive image filenames and alt text (subject, medium, style, dominant colors) for search discoverability — generic filenames (IMG_1234) forfeit this for free.

## Patterns (name — when to use — when to avoid)
- Visible pricing / "inquire for price" toggle — default to visible pricing for direct-to-collector sales — avoid only when gallery representation agreements require price-on-request.

## Anti-patterns
- Treating Instagram as sufficient infrastructure (algorithm-dependent, no owned data, reach can collapse without warning).
- Sub-2000px images or missing per-piece metadata.
- No mobile-specific testing before launch.

## Checklist (only if supported)
- All five core sections present.
- Every artwork has dimensions/medium/year/availability and either a price or explicit inquire path.
- Mobile load tested under 2 seconds with real touch gestures.
