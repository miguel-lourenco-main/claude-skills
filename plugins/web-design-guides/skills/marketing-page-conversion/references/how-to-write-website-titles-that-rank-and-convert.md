## Use when
Writing or auditing `<title>` tags for any page (homepage, product, landing, blog).

## Rules
- Target length: 40–60 characters; titles in this range had an 8.9% higher click-through rate than titles outside it (per Backlinko's analysis of 4M search results, per guide). Keep the most important words within the first 40 characters to survive mobile truncation.
- Put the primary keyword at the very beginning (first 3–5 words). Placing the primary keyword at the front of product-page titles increased organic traffic 11% in a controlled test (per SearchPilot, per guide).
- Put brand name at the end, or omit it, unless the brand itself is well-known or the query is navigational (someone searching the business name directly). Moving brand names to the front of title tags caused a 6.7% decrease in clicks in split testing (per Semrush, per guide).
- Match title framing to query intent: informational ("How to," "Guide," "What is" + topic-first) / transactional (lead with an action verb — "Buy," "Book," "Order" — plus a concrete offer) / navigational (brand name first, standard page name like "About," "Contact").
- Never duplicate titles across pages — duplicate titles measurably lower CTR because users can't distinguish result entries (per Semrush, per guide). Never use generic placeholders ("Home," "Services," "Products").
- Avoid keyword stuffing (repeating the same keyword phrase multiple times) — Google rewrites roughly 58% of title tags, with stuffing a major trigger (per Moz, per guide). Avoid exceeding the character limit — titles over it are 57% more likely to be rewritten by Google (per Ahrefs, per guide).
- Don't let a title over-promise relative to page content ("Complete Guide to X" on a thin page) — misleading titles hurt both rankings and user trust per Google's own guidance.
- Drop outdated year references in titles; stale-looking dates can trigger freshness-related rewrites/demotions.
- To find titles worth fixing: pull Search Console data, sort by impressions descending, flag any page with CTR below ~3% (or ranking position 5–10 with ~2% CTR) as a title-rewrite candidate.
- Testing a title change: record baseline (impressions, clicks, CTR, position) for 1–2 weeks before changing anything; after the edit, request re-indexing and wait 2–3 weeks before comparing; success = CTR up with stable or improved position.

## Patterns (name — when to use — when to avoid)
- Keyword-first, benefit-hook title ("Emergency Plumber Boston | 24/7 Same-Day Service") — use for any service/product/landing page competing on a specific search term — avoid for navigational/brand-search pages, where brand-first is correct instead.

## Anti-patterns
- Duplicate titles across multiple pages.
- Generic single-word titles ("Home," "Products").
- Keyword-stuffed titles repeating the same phrase.
- Titles that exceed ~60 characters and get truncated mid-phrase.
- Titles promising content depth the page doesn't deliver.

## Checklist
- [ ] 40–60 characters, primary keyword in first 40
- [ ] Primary keyword at the front (except navigational/brand-search pages)
- [ ] Brand name at end or omitted (unless brand is well known)
- [ ] No duplicate titles across the site
- [ ] No keyword stuffing, no stale year references
- [ ] Title content promise matches actual page content
