## Use when
Auditing or building a conversion-focused landing page and deciding which fixes to prioritize with limited time/traffic.

## Rules
- Fix in impact order: form length, then headline clarity, then mobile friction, then page speed, then proof placement. Don't polish visuals before these.
- Forms: collect only name + email at the point of conversion; push other qualification fields to post-conversion follow-up or onboarding. Shortening an 11-field form to 4 fields produced a 120% conversion increase (per Imagescape, per guide).
- Headline must answer "what's in it for me" within 5 seconds; if an unfamiliar reader can't restate the offer after reading it, rewrite before doing anything else.
- CTA verb choice matters: "Trial for free" reads as lower-commitment than "Sign up for free" and lifted trial starts 104% in a cited case study (unsourced attribution beyond "case studies show" — mark unsourced).
- One primary CTA per page, repeated at hero / mid-page / end. Secondary offers ("Watch Demo," "Download Guide") must be visually subordinate to the primary CTA, not competing.
- Route different traffic sources (organic, paid, email, social) to distinct landing pages rather than one generic page; companies with 31–40 landing pages generate 7x more leads than those with 1–5 (unsourced numeric claim in guide — mark unsourced).
- Copy: 15–20 word max sentences, active voice, ~8th-grade reading level. Strip nav links that don't serve the conversion goal.
- Mobile touch targets: minimum 48x48 CSS px with 8dp spacing (per Google's official guidance, per guide); Nielsen Norman Group recommends a 1cm x 1cm physical minimum (per NNG, per guide).
- Mobile forms: single-column layout beats side-by-side fields; set correct input types (numeric keypad for phone, easy @ for email).
- Page speed: compress images, use a CDN, enable browser caching — each is a self-contained, low-effort fix; treat deeper server-response tuning as unnecessary until load time exceeds 3 seconds.
- Testimonials: use full name, photo, job title, and a specific quantified outcome (e.g. "+40% email revenue in 3 months"); generic praise ("thousands of happy customers") is worthless — replace or cut it.
- Match testimonial content to the objection at that point in the page (ease-of-use proof near onboarding-anxious sections, ROI proof near pricing-anxious sections).
- Loss-framing ("stop losing X") outperforms gain-framing ("gain X") when anchored to a real, specific, data-backed cost — never fabricate the loss claim.
- A/B testing with low traffic (<1,000 weekly visitors to the tested page): don't test, just apply known-good practices in priority order above. With sufficient traffic, test one element at a time for 2–4 weeks minimum.
- Templates are good enough (avg. ~6.6% conversion, unsourced in this guide) until you have a proven high-LTV offer, 1,000+ monthly conversions worth of traffic, and a specific need templates can't meet — only then justify custom build cost.

## Patterns (name — when to use — when to avoid)
- Single dedicated landing page per traffic source — use whenever running distinct campaigns/ads/segments — avoid defaulting all traffic to one generic page.
- Progressive profiling (minimal form now, more data later) — use for any lead-gen form beyond name+email — avoid asking for qualification data up front.

## Anti-patterns
- Multiple competing CTAs of equal visual weight.
- Generic, unquantified social proof.
- One landing page serving every traffic source and message.
- Fabricated urgency or unsupported loss claims.
- Running A/B tests on multiple elements simultaneously with low traffic.

## Checklist
- [ ] Form has ≤4 fields (name + email minimum)
- [ ] Headline passes 5-second "what's in it for me" test
- [ ] Single primary CTA, repeated 3x, alternatives visually secondary
- [ ] Distinct landing page per traffic source/campaign
- [ ] Testimonials are specific, named, quantified, and positioned against known objections
- [ ] Touch targets ≥48x48px, single-column mobile forms
- [ ] Images compressed, CDN enabled, caching on
