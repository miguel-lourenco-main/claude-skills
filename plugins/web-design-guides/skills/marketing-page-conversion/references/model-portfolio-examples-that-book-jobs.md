## Use when
Designing a portfolio that must communicate range/fit within a very short (under ~60s) review window, where the reviewer is scanning for a specific "look" or category match rather than reading narrative.

## Rules
- When review time is extremely short, presentation strategy should match the work type: video/motion for personality-forward roles, minimalist full-bleed galleries when image quality alone must carry the pitch, grid layouts when the reviewer needs to scan range fast without clicking through.
- Organize by the categories the reviewer actually searches for (e.g. "Advertising," "Runway," "Portrait") rather than generic "versatility" — this saves the reviewer time and is the single most repeated pattern across examples.
- Keep contact/booking info persistent (sticky header or nav) so interest converts immediately without hunting.
- Match presentation style honestly to actual market position/career stage — a portfolio that overclaims relative to real experience is spotted immediately by experienced reviewers.
- A dark/black background can be used deliberately to increase contrast and make image-heavy work read as "art" rather than plain reference material — a stylistic choice, not a default.

## Patterns (name — when to use — when to avoid)
- Video-forward homepage — when personality/movement is part of what's being cast — avoid when the work is purely still/editorial and video would dilute focus.
- Pure minimalism (images only, near-zero copy) — when image quality is exceptional and genuinely needs no explanation — avoid if the work requires context to be understood correctly.
- Category-based navigation — whenever the audience searches by type/genre — avoid for a narrow single-specialty portfolio where categories would be mostly empty.

## Anti-patterns
- Presenting a portfolio that implies more range or experience than actually exists.
- Burying booking/contact info below scrollable galleries.

## Checklist (only if supported)
- Contact/booking path visible without scrolling.
- Categories reflect how reviewers actually search this field, not internal chronology.
