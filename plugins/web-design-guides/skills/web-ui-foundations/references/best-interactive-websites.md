## Use when
Deciding whether — and which kind of — interactivity (scroll-driven narrative, 3D/WebGL, cursor-reactive effects, quizzes/personality tests, swipeable/playful cards) fits a given site's goal.

## Rules
- Match interaction technique to content type and goal, not to trend appeal:
  - Narrative/emotional content (nonprofit storytelling, origin stories, sequential events) → scroll-driven storytelling (scroll position drives progressive reveal, e.g. via scroll-scrubbed animation).
  - Technical/portfolio/brand-immersion work → 3D/WebGL (spatial exploration, cursor-reactive shaders) to demonstrate capability, not just decorate.
  - Personalization/lead-qualification/shareability goals → quizzes and interactive tools (results people want and want to share).
  - Task-focused sites (ecommerce checkout, forms, SaaS tools where speed matters) → minimal animation, clear feedback; spectacle competes with completion.
- User-driven pacing (scrollytelling, swipeable cards, click-to-explore) increases engagement because it puts the user in control of reveal speed — the mechanism, not just the animation itself, is what builds investment.
- Brand personality should run through the interaction style itself (e.g., playful swipe/hover for a tropical/fun brand, precise cursor-reactive shader work for a technical agency), not just through copy or color.
- Interactive elements can double as functional navigation and as a capability demonstration simultaneously (e.g., an agency site whose hover/drag interactions are themselves portfolio pieces).

## Anti-patterns
- Applying heavy scroll/3D/WebGL interaction to task-focused flows (checkout, form submission) where speed and predictability matter more than spectacle.
- Poorly executed animation that removes user agency/control — unsourced but flagged as a documented risk (guide cites Nielsen Norman Group generally, without a specific stat) of harming engagement rather than helping it.

## Checklist
- Name the site's primary goal (narrative/emotional, technical-showcase, lead-qualification, or task-completion) before choosing an interaction pattern.
- For any expressive/decorative interaction, confirm it doesn't sit on a task-critical path (checkout, signup, core conversion action).
